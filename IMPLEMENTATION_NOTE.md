# Implementation Note

**Tools and frameworks used:** React, JavaScript, Vite, and Tailwind CSS v4. The finished site is hosted on Vercel.

**Design decision:** I redesigned the opening section as a split hero, pairing the Pahrump landscape photo with a short introduction and a prominent “Find your dream home” button. This gives the homepage a clearer visual hierarchy than the reference and makes the main action easy to find on mobile, tablet, and desktop.
